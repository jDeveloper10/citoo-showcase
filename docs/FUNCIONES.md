# Funciones

## Para el salón

| Área | Qué permite |
|---|---|
| **Perfil del negocio** | Nombre, categoría, descripción, dirección, logo y color de marca. Un interruptor para publicar el salón en el directorio. |
| **Servicios y equipo** | Catálogo con precio y duración, y las profesionales que los realizan. |
| **Portafolio** | Galería de diseños y trabajos para mostrar a las clientas. |
| **Agenda** | Citas confirmadas y pendientes, incluidas las clientas sin cuenta. |
| **Inventario** | Insumos por categoría con estados de stock, y descuento automático al vender. |
| **Costeo** | Materiales con costo, gastos fijos, mano de obra y margen propio para llegar al precio justo de cada servicio. |
| **Ventas** | Registro de ventas del día a día. |
| **Reportes** | Vista financiera del negocio. |
| **Fidelidad** | Cuentas de puntos por clienta. |

## Para la clienta

- Buscador de salones por nombre o tipo.
- Detalle del salón con servicios, precios, equipo y trabajos.
- Reserva guiada: servicio, profesional, fecha y horario.
- Sus citas en un solo lugar.
- Su tarjeta de puntos.

## Avisos

- Correos de bienvenida, nueva cita, confirmación y cancelación.
- Notificaciones web para el salón y para las clientas.
- Alerta de stock bajo para el salón.

## Páginas públicas

- Página principal con buscador de salones.
- **Una página de reservas por salón**, instalable como aplicación en el celular.
